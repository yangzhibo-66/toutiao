# 微信小程序目录说明

这个目录是基于原有 `Vite + Vue` 新闻项目新增的一套原生微信小程序工程。

## 导入方式

1. 打开微信开发者工具。
2. 选择当前仓库根目录 `C:\Users\yzb\Desktop\小程序\今日头条\03-前端项目代码\xwzx-news`。
3. 工具会读取根目录下的 `project.config.json`，并自动把 `miniprogram/` 识别为小程序源码目录。

## 需要改的配置

- 后端地址在 `miniprogram/utils/config.js`
- 默认是 `http://127.0.0.1:8000`
- 真机预览或正式上传前，必须改成你自己的可访问后端地址，并在微信公众平台配置合法域名

## 当前已迁移的功能

- 首页分类新闻
- 分类页
- 新闻详情
- 登录注册
- 我的收藏
- 浏览历史
- 我的页面

## 当前做的兼容处理

- 原 H5 项目的 `vue-router`、`Vant`、DOM 操作已经改成微信原生页面写法
- AI 聊天页没有继续暴露前端 API Key，而是先改成说明页，避免小程序泄露密钥
- 原文链接在小程序里改成“复制链接”，因为小程序不能像 H5 那样直接打开任意外链
